# Assets

This directory stores reusable fonts, images, music, sound effects, and battery profiles, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

### Muyu application fonts

- `fonts/muyu-noto-sans-sc-subset.otf` is a 29.8 KB application subset of
  [Noto Sans SC Regular](https://github.com/notofonts/noto-cjk/tree/main/Sans),
  distributed under the [SIL Open Font License 1.1](fonts/muyu-noto-OFL.txt).
  Source and subset SHA-256 values are recorded in `fonts/muyu-font-manifest.json`.
- `fonts/muyu-characters.txt` is the authoritative UI character inventory;
  printable ASCII U+0020–U+007E is also included. The subset deliberately does
  not support arbitrary Chinese input.
- `fonts/muyu_font_16.c` / `fonts/muyu_font_20.c` export `muyu_font_16` /
  `muyu_font_20`: uncompressed 4 bpp LVGL fonts, generated by `lv_font_conv@1.5.3`.
  Compile these files once in the application and select the font on every
  Chinese label. Do not disable LVGL missing-glyph placeholders.
- Regenerate from the retained OTF and SVG with `node tools/generate_muyu_assets.mjs`
  after installing the exact asset-only dependencies using
  `npm install --prefix build/muyu-assets-tools --no-audit --no-fund --save-exact lv_font_conv@1.5.3 sharp@0.34.5`.
  Font inventory changes require re-subsetting the full official source using
  `fonttools==4.60.1` and
  `python tools/generate_muyu_assets.py --subset /path/to/NotoSansSC-Regular.otf`.
- Run `python3 tools/generate_muyu_assets.py --check` to inspect the emitted
  LVGL cmaps, compare real UI string coverage, check glyph IDs, and exercise
  the intentionally absent U+9F98 negative case. Bitmap output and widget
  binding still require physical display acceptance.

### Guandan scoreboard fonts

- `fonts/guandan_noto_subset.otf` is an application subset of Noto Sans SC
  Regular 2.004; `fonts/guandan_montserrat_bold_subset.ttf` is a subset of
  Montserrat Bold 8.000 from the pinned LVGL 9.5.0 source tree. Their SIL OFL
  1.1 licenses are `fonts/guandan_noto_OFL.txt` and
  `fonts/guandan_montserrat_OFL.txt`. Upstream URLs and source/subset hashes
  are retained in `fonts/guandan_font_manifest.json`.
- `fonts/guandan_characters.txt` plus printable ASCII is the 131-character
  inventory for `guandan_font_14` and `guandan_font_18`. The large
  `guandan_font_84` contains only `0123456789JQKA`, covering all 15 ranks from
  2 through A3. All generated fonts are uncompressed 4 bpp LVGL sources.
- Regenerate with `python3 tools/generate_guandan_assets.py --generate` after
  `npm install --prefix build/guandan-assets-tools --no-audit --no-fund --save-exact lv_font_conv@1.5.3`.
  For inventory changes, use the script's two `--subset-*` options with the
  full source fonts and `fonttools==4.60.1` before regenerating.
- `python3 tools/generate_guandan_assets.py --check` checks real generated
  cmaps, UI string coverage, a missing-glyph negative case, and subset hashes.
  `python3 tools/render_guandan_preview.py` exercises the actual application
  UI with LVGL 9.5.0 and a 24 KB heap. It uses `LV_USE_THEME_DEFAULT=0` and
  `LV_USE_THEME_SIMPLE=1`, matching the firmware: the unused full theme must
  not consume the heap needed by the large rank glyph buffers. These host
  checks do not replace physical-display acceptance.

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

Original Guandan cover and reset illustrations: `images/guandan-{cover,reset}-1152x1536.{svg,png}`. Both are 1152 x 1536 portrait interface renderings, not hardware photographs. The SVGs use outlined text and have no external dependencies; their matching PNGs were rendered and visually checked before submission. Artwork follows the repository MIT license; Noto Sans SC and Montserrat letterforms retain their font-license notices above.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

## Battery profiles

[`battery/wanli-500mah-profile2-xil40x-20261020.txt`](battery/wanli-500mah-profile2-xil40x-20261020.txt)
contains the supplied CW2017 profile for the Wanli New Energy 500 mAh cell
(profile2, XIL40X, 2026-10-20). It is an unchanged copy of the project-supplied
file, retained at the maintainer's request for this firmware update. Its
original filename is recorded in the paired Chinese document. No separate
license was included in the supplied file.

The format is 80 lines of two hexadecimal digits, one byte per line in register
order. The BSP embeds those bytes in `components/bsp/src/bsp_battery.c`; the
host gate checks the source file and initializer for an exact match. Text-file
SHA-256: `7ea96eba4634f4495a37c25ffacd54c1deaa0693b162c892d671a2ba68460919`.
Decoded 80-byte SHA-256:
`fa7365671093ef449c5bdcfb4adb279e3d275f888109f50b6b2f21e9b96220d5`.
This is a fuel-gauge profile, not a charging configuration or a generic profile
for every 500 mAh cell; see the [hardware guide](../docs/hardware-design/AI_HARDWARE_DEVELOPMENT_GUIDE.md#9-cw2017-fuel-gauge).
